# 開発者・エージェント向け指示

- 変更前に `README.md` と `DEVELOPMENT_RULES.md` を読む。
- 実装・仕様・使用法が変わる場合は、関連文書と開発ログも更新する。
- 複雑な実装は、実装担当とは別の担当者が独立してレビューする。
- PremiereのActionは対象Projectの `lockedAccess()` 内で生成し、同じロック内のTransactionで実行する。
- 案件データ、顧客名、実際の制作セリフ、個人のホームディレクトリ、認証情報をテストや文書へ追加しない。
- テスト例には架空データを使う。実機で確認していない動作を確認済みと記載しない。
- ビルド生成物、Python本体、モデル重み、案件設定、音声・動画、ログをコミットしない。
