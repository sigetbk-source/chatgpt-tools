# ナレーション差分更新の使い方

## 入口

Premiereの「ウィンドウ → UXPプラグイン → Premiere制作支援」を開き、
「ナレーション」タブを選ぶ。新規制作、生成済み音声修正、台本差分更新は
すべてこの案件カードから開始する。

連携サーバーはパネル表示時に自動起動する。右上が「接続済み」になり、案件カードが表示されることを確認する。初回だけ外部プロセス起動の許可が表示される場合がある。自動起動できない場合は、右上の「連携サーバーを起動」を押す。アクセスできない古いクラウド案件が履歴に残っていても、利用可能な案件カードは継続して表示する。

## 生成済み音声を修正する

1. Premiereへ反映済みの対象案件で「生成済み音声を修正」を押す。
2. ブラウザで修正対象のN番号を再生する。
3. 必要に応じてテロップ本文、読み上げ用本文、話者、速度を変更する。
4. 修正した行の「再生成」を押して音声を確認する。
5. 「音声修正を承認」を押す。
6. Premiere制作支援へ戻り「Premiereへ音声修正を反映」を押す。
7. パネルが「SRT貼り直し待ち」になったことを確認する。
8. 古いキャプショントラックを削除する。
9. 「ナレーションTimeline配置」互換パネルで「差分更新後のSRTを反映」を押す。成功後に貼り直し待ちが解除される。

音声もテロップ本文も変わらなかった行は既存WAVを再利用する。修正音声の尺が変わった場合は後続WAVを実尺で詰め、SRTも同じ時刻へ同期する。音声修正のたびにSRTの貼り直しは必須とする。

## 通常の差分反映

1. 「修正版台本を比較」でWordまたはPDFを選ぶ。iPhone等で再保存され、ページ内の文字行が連結されたPDFも自動で本文欄を復元する。
2. 表示された変更・追加・削除を確認する。ほぼ全件が長文の変更として出た場合は、そのまま生成せず、差分一覧上部の「修正版台本を選び直す」から同じ台本を選び直す。
3. ブラウザで差分音声を確認し、承認する。
4. Premiereの「文字起こし修正テスト」パネルで「Premiereへ差分反映」を押す。
5. 完了後、既存の古いキャプショントラックを削除する。
6. 「ナレーションTimeline配置」パネルで「差分更新後のSRTを反映」を押す。

音声の1フレーム空白は差分反映時に自動補正され、SRTも補正後の実時刻で生成される。

「差分更新後のデータがありません」と表示された場合は、対象のPremiereプロジェクトを保存して開いていることを確認し、「ナレーションTimeline配置」パネルを閉じて開き直す。最新SRTが同じプロジェクト用であれば、パネルが自動的に最新データへ紐付け直す。別の `.prproj` や複製プロジェクトを開いている場合は誤反映防止のため採用しない。

画像だけのPDFは対象外。文字を選択できるPDF、またはWord版を使用する。

## 音声だけ補正されてSRTとずれた場合

1. 「Premiere制作支援」パネルの「ナレーション」タブを開く。
2. 対象案件の「音声とSRTの隙間を詰める」を押す。
3. 完了メッセージを確認する。既に音声が詰まっている場合は移動件数が0件でも正常で、同期済みSRTは新しく生成される。
4. 古いキャプショントラックを削除する。
5. 「ナレーションTimeline配置」パネルで「差分更新後のSRTを反映」を押す。

古いキャプショントラックを残したまま新しいSRTを反映しないこと。音声とSRTの同期処理は音声の順序や本文を変更しない。
