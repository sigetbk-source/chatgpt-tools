# ローカル版の起動と通常インストール

実行環境は `~/Library/Application Support/Premiere制作支援/` に置く。書類・デスクトップのiCloud同期から実行コードを分離する。

- `python/`: 専用Pythonと依存部品。
- `app/`: 文字起こし・連携サーバー・補助ローダー。
- `narration/`: ナレーション制作画面。
- `app/work/uxp/`: ジョブ・辞書・連携状態。旧IPC要求は再生しない。
- `logs/`: 起動ログ。
- `backups/`: 変更前の配置パネル。

通常利用ではDeveloper ToolsでLoadしない。Premiereの「ウィンドウ → UXPプラグイン → Premiere制作支援」を開く。通常版は0.4.1。CEPの「ナレーションTimeline配置」は引き続き初回音声・字幕配置に使う。

別案件は先にそのPremiereプロジェクトと配置先シークエンスを開き、配置パネルを一度閉じて開き直す。「制作画面を開く」で案件フォルダ・台本・音声＋テロップを選択し、ブラウザで生成・確認後にPremiere用へ書き出す。表示案件を確認し、空の音声トラック番号を指定して反映する。

独立した制作画面は `~/Applications/ナレーション制作ツール.app` から開ける。デスクトップに残っている旧アプリは控えとして保持し、通常起動には使わない。

起動時に利用可能なPythonを確認する。起動失敗はパネルへ表示する。更新直後は既に開いているCEPパネルを閉じて開き直して、新しいコードを読み込ませる。

台本・生成WAV/SRT・案件編集データは元の案件フォルダに残す。未ダウンロードの過去案件は、履歴を消さず未取得と表示する。必要な案件を使うときだけFinderで取得する。Whisperモデル本体は今回コピーしていないため、必要時にローカルのモデルキャッシュへ取得する。音声生成サービスの接続要件は変わらない。

インストール前のコード、案件、生成物は削除しない。通常版の登録はAdobe UPIAで確認する。パネルを開くためのUDT操作と、ブラウザからの既存自動書き戻しが内部で使うUDTは別の機能である。
