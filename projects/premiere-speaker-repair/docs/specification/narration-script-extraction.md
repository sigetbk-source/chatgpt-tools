# ナレーション台本抽出仕様

## 対応入力

- Word（`.docx`）
- 文字層を持つPDF（`.pdf`）

画像だけのPDFには対応しない。横書き・縦書きは入力内容から自動判定する。

## Nブロック

- 行頭の `N`、`Ｎ`、`NA`、`ＮＡ` と、その後の本文を開始行とする。
- 空白行または次のN開始行で現在のブロックを終了する。
- PDFで空白行情報が失われた場合は、明確な画指示（`＊`、`※`）、`ON`、話者名から始まる引用台詞を終了境界として扱う。
- 比較用本文では改行を空白へ畳み、読み上げ用の `speechSource` では本文内の改行を保持する。

## 未タグPDFの復元

iPhone等で再保存された未タグPDFでは、通常の文字抽出がページ内の複数行を一つの長い行へ連結することがある。1ページの抽出行数が少なく、一つの行に複数のN開始記号が含まれる場合は、次の処理へ自動で切り替える。

1. PDF内の文字片から実ページ座標を計算する。
2. N記号の代表X座標から、二列台本の右側本文欄を特定する。
3. 同じY座標の文字片を見た目の行へ再結合する。
4. 行間の距離から空白行を復元する。
5. ページ本文と異なる変換倍率を持つ手書き注釈を除外し、壊れた文字マップが本文へ混入するのを防ぐ。

通常抽出が正常なPDFとWordには、この座標復元処理を適用しない。

## 安全条件

- 座標復元後にNブロックが一件も得られない場合は、通常抽出へ戻す。
- 差分比較の正本は現在の `narration.json` とし、台本抽出だけで管理データを上書きしない。
- ユーザーが差分対象を確認し、音声を承認するまではPremiereへ反映しない。
