# ローカル実行環境仕様

実行時ルートは `~/Library/Application Support/Premiere制作支援/`。開発元リポジトリを実行時の参照先にしない。Pythonは単独再配置可能な配布物をコピーし、必要な依存部品を公式PyPI wheelで構成する。venvのリンクやeditable-installでiCloudへ戻らない。

UXPのIPCと診断ログは同じローカルルートを参照する。通常CCXをAdobe UPIAで登録し、インストール後にも拡張子なし起動ファイルの実行権限を確認する。UXPの編集Actionと既存権限は変更しない。

CEPは専用ローカルPythonを優先して実行可否を確認する。代替候補も実行可能な場合だけ使う。標準Pythonの存在だけで成功としない。stderr・子プロセス起動/終了エラーをパネルへ表示する。古い起動の遅延通知が新しい起動や承認待ち状態を解除しないよう起動IDで照合し、承認時刻の基点は起動成功時とする。

既存状態はジョブ・案件別辞書・話者情報のJSONをすべて検証してスナップショット化する。元のファイル集合・内容を切替前後に比較し、変更があれば中止する。旧IPC要求は移行しない。連携サーバーの処理中状態とバックグラウンド状態を確認してから切り替える。失敗時はCEPを復元し、旧連携をローカルPythonで再起動する。

過去案件のconfig・辞書・文字起こし・反映準備ファイルは、SF_DATALESSを内容読み取り前に確認する。未取得なら履歴レコードの状態を変更せずoffline表示を返す。ナレーションの履歴も同様に扱う。

モデル重みと案件素材は実行コードとは別管理。今回の移行で元の案件やモデルを移動・削除しない。既存の時刻ベースの承認照合には、別ブラウザ案件の同時書き出しを完全には識別できない既存制約がある。
