# Changelog

このプロジェクトの利用者に関係する変更を記録します。形式は Keep a Changelog を参考にし、リリース版から Semantic Versioning を適用します。

## Unreleased

### Added

- Ticket Launcher MVP の要求仕様と受け入れ条件
- GitHub を開発正本とする AI 開発標準ルール
- 開発ログと変更履歴の運用
- SwiftUI Xcode プロジェクト
- 発売 5 分前と3 分前の通知仕様
- チケット予定の登録、編集、削除、端末内保存
- 発売予定と発売済みイベントの一覧表示
- HTTPS販売ページを開く明示的なボタン
- 発売5分前と3分前のローカル通知
- 通知タップから保存済みイベントを照合して発売待機画面を開く導線
- 発売待機画面のカウントダウンと自動ロック抑止
- 前面待機中の発売時刻にSafariで販売URLを自動表示
- 起動時と前面復帰時の通知再同期
- 通知タップ後の前面復帰で、予約済みの後続通知が失われる可能性を修正

### Fixed

- 実機で通知をタップした際にメインスレッド例外で停止し、発売待機画面のカウントダウンとSafari自動表示へ進めなくなる問題

### Known limitations

- 発売時刻のSafari自動表示は、発売待機画面を前面に表示し、iPhoneをロックしない場合に限られます。
- iOS の制約上、バックグラウンドまたはロック中に販売 URL を自動で開くことは保証できません。
