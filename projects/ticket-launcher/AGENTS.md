# AGENTS.md

このリポジトリで作業する AI エージェントは、着手前に `README.md`、`DEVELOPMENT_RULES.md`、対象機能の `docs/` を読むこと。

## 正本

- GitHub 上のコードと Markdown を開発の正本とする。
- 仕様、設計、手順、判断、変更履歴をリポジトリ内に残す。
- 外部メモへ転記する場合も、このリポジトリからの一方向の参照とする。
- パスワード、トークン、証明書、Provisioning Profile、個人情報をコミットしない。

## 変更時の必須事項

- 要求範囲を小さな変更単位に分ける。
- 実装と同時に、関連する README、仕様、開発ログ、CHANGELOG を更新する。
- iOS の制約を回避できるように見せかけたり、未検証の動作を保証と記載したりしない。
- 通知、日時、URL 起動、永続化は境界条件と失敗時の動作をテストする。
- 既存ファイルのルールを無断で削除・弱体化しない。

## 完了条件

複雑な実装は、実装担当とは別のレビュー担当が確認する。問題があれば、必要な範囲で修正と再レビューを繰り返す。

完了と報告できるのは、次のすべてを満たした場合のみ。

1. 要求仕様と受け入れ条件を満たす
2. 既存機能への重大な回帰がない
3. 関連する自動テストと必要な実機テストが通る
4. README、仕様、開発ログ、CHANGELOG が現状と一致する
