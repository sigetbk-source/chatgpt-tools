# 多言語文字起こし確認画面

`python/multilingual_review.py` は既存の日本語確認経路とは別のローカル入口である。入力masterと素材は読み取り専用で、修正状態は指定した作業フォルダーへ保存する。

ISO素材の資料補正は、同じ発言に対する独立した候補を一つの補正済み本文に合成し、原語欄の既定の編集欄として日本語参考訳の左側へ置く。置換された語句全体を網掛けし、採用後も網掛けを残す。さらに手動修正しても、補正語句が本文内に一意に残る場合は網掛けを追随させ、消えた語句や重複して位置を決められない語句は網掛けしない。修正済み本文は一度の操作・Undo履歴として保存する。変更点と最初のASR原文は折りたたみ内で確認する。候補が同じ文字位置で競合する場合は自動合成せず、個別に確認する。画面の⌘Z／⌘⇧Zは入力欄以外で作業履歴を戻す／やり直す。入力欄では通常の文字編集Undoを優先する。

```sh
python3 python/multilingual_review.py \
  --master /absolute/path/master.json \
  --workspace /absolute/path/multilingual-work \
  --media /absolute/path/source.mp3 \
  --speaker-ids /absolute/path/speaker-ids.json \
  --aai-response /absolute/path/saved-aai-response.json \
  --japanese-url http://127.0.0.1:8899 --port 8901
```

`--japanese-url` は実際に起動している従来画面を利用者が指定する場合だけ表示する。自動で推測しない。保存済みAAI応答は候補作成だけに使い、明示採用まで原文を変えない。

## 保存形式と操作

各発言に `language`、`language_source`、`text_override`、`alignment_status`、`translation`、`retry_candidates` を追加する。音声全体のAAI言語を各発言へコピーせず、初回は `??-??`（未指定）にする。話者と言語は独立操作であり、言語変更だけでは外部処理を開始しない。

本文の保存状態は発言カード内のボタン横に表示する。本文が保存済みと同じなら「保存済み」としてボタンを無効にし、編集時は「未保存の本文あり」へ切り替える。入力を元へ戻した場合は未保存判定を解除する。資料補正候補が残る場合は「資料補正は未採用」と表示し、採用・保存操作を有効にする。発言カードの主欄は「本文」と呼び、結合先などの補助説明は本文より小さくする。本文欄は内容に合わせて縦に広がり、欄内の縦スクロールを使わず全文を読めるようにする。

「話者を管理」ダイアログでは、既存話者名の編集と新規話者の追加をまとめて保存またはキャンセルできる。既存話者のキーとPremiere UUIDは変更しない。空の名前と重複名は拒否する。発言カードから開いた場合、新規話者をその発言へ割り当てるチェックを明示した時だけ割当も行う。名前変更・追加・任意の割当を一回の操作履歴として保存し、まとめてUndo／Redoできる。削除は提供しない。

「次と結合」は画面の絞り込みに関係なく、時間順で直後の発言を対象にし、対象時刻と話者をボタン横へ表示する。結合後の話者は先頭発言を維持する。両側の原文を連結する。同じ英語区間同士で境目に空白がない場合は半角スペースを一つ挿入し、元の単語時刻に対応する文字列にも反映する。訳は両方を保持したうえで更新待ちにする。両側の言語が同じなら維持し、異なる場合は未指定・要確認へ戻す。再起こし候補は履歴として保持するが、未採用候補は古い候補として採用不可にする。両側の注釈は `merge_provenance` に残す。発言時刻が重なる場合も元の単語時刻を保持して結合し、整列未解決としてPremiere JSONへの出力を保留する。結合対象の原文・訳に未保存入力がある場合は、結合操作で一緒に保存する。Undoでは結合直前の編集済み本文と訳へ戻す。別の発言の未保存入力は、区間番号を更新して保持する。

重複した起こしを除く「区間を削除」は、対象の時刻・話者・本文を確認ダイアログに表示してから確定する。対象の未保存入力があれば先に保存を求め、操作直前に本文・話者・言語・単語時刻の指紋を照合する。削除は作業用masterだけに適用し、元の音声・入力masterを変更しない。最後の1発言は削除できない。削除後もUndo／Redoで復元でき、別の発言の未保存入力は区間番号を更新して保持する。

原語欄の文字入力位置（挿入位置）を記録し、「入力位置で分割」のボタンへ移動してもその位置を維持する。文字列の表示位置はUTF-16で扱う。選択範囲を解除し、本文の前後が空でない位置なら、単語境界以外でも一回のクリックで本文を二分する。単語時刻と一致する境界では既存の単語時刻をそのまま分ける。補正済み本文や単語途中の位置では、本文中の入力位置の割合から音声時刻を推定し、近い元の単語境界で既存の単語時刻を二分する。音声境界は推定値として扱い、両側とも整列未解決のまま保存する。元の単語時刻が1語だけになった区間も再分割できる。この場合は入力位置から音声境界を推定して両側に仮の時刻を置き、整列未解決を維持する。分割前の単語・訳・本文を履歴に残す。分割後の訳はそれぞれ未入力として確認を求め、Premiere JSON出力は両側の時刻整列が済むまで保留する。対象の未保存入力は分割操作で一緒に保存する。分割後に各訳を割り当て直せるよう、分割前の訳は履歴に残す。Undoでは分割直前の編集済み本文と訳へ戻す。別の発言の未保存入力は区間番号を更新して保持する。補正箇所の網掛けは編集欄から離れたときに表示し、ポインタで本文を編集している間は入力欄自身の文字を表示して挿入位置と見た目を一致させる。⌘スペース（従来の⌘Enterも可）は、原語本文に入力位置がある場合、その位置に対応する単語時刻から再生する。本文変更後など単語時刻が未確認なら区間内の文字位置から概算する。本文に入力位置がない場合は、フォーカスまたはポインタのある発言カードの先頭から再生する。再度押すと一時停止し、カードを選んでいない場合はプレーヤーの現在位置から再生する。

重なった発言を分割した作業データでは、別の発言が一時的に開始時刻順でない場合がある。この状態でも単語境界での分割と話者変更は対象発言を検査して実行し、他の発言の並びによる全件検査エラーで止めない。分割の失敗理由は画面上部に加え、押した発言カードのボタン直下にも表示する。時刻順でない作業データのPremiere JSON書き出しは引き続き検証対象であり、この変更では自動的に並べ替えない。

保存・分割・結合などの操作を押すと、直ちに押したボタンを「処理中」表示へ変え、操作ボタンを一時的に無効化する。応答後に保存済み状態を読み直して画面を再描画し、成功または失敗を表示してから操作を戻す。処理中の二重送信は受け付けない。

区間削除は確認ダイアログを挟まず即時に保存し、画面上部の「元に戻す」または⌘Zで復元できる。対象区間に未保存の本文・訳がある場合は削除せず、先に保存するよう表示する。編集履歴は `workspace/history/` に圧縮して個別保存し、`state.json` は現在の作業状態と履歴参照だけを保持する。従来の一体型履歴は起動時に移行し、元ファイルを `state.pre-history-migration.json` として残す。

確認対象を限定した一回限りのテキスト判定結果は、`/api/language/infer-apply` で一括適用できる。指定境界より後で、現在の言語が未指定かつ手動確認済みでない発言だけを受け付ける。全件を事前検証し、一件でも条件外なら何も変更しない。適用結果は `language_source=inferred` とし、`language_inference` に `provider=text-review`、理由、信頼度、要確認状態を保存する。画面では「推定・要確認」と表示する。外部APIやモデルはこの処理から呼ばない。一括適用は一回のUndoで戻せる。

本文を単語列と異なる内容へ変更した場合は `alignment_status=unresolved` とし、時刻を捏造しない。発言カードの「単語時刻を整列」から、本文を語ごとに改行し、対象発話の再生位置を秒で見ながら試聴できる。単語時刻がすでにある区間にも「単語時刻を調整」を表示する。この場合は各語の開始・終了を既存時刻で埋め、ずれた語だけ変更して保存できる。語間の無音も保存時に維持する。各単語の「試聴」は入力欄の開始時刻ちょうどから終了時刻まで再生し、前後の余裕を付けない。発話の開始位置は同じ画面で変更でき、▲または上キーで0.1秒早め、▼または下キーで0.1秒遅らせる。「新しい開始から試聴」は指定時刻ちょうどから再生し、再生中は一時停止ボタンになる。開始を変えても当該発話の終了と次の区間の開始は固定する。早めた結果、直前の区間に食い込む場合だけ、その区間の終了を新しい開始へ短縮する。単語時刻は自動推定せず、変更後の発話区間からはみ出す単語があれば `unresolved` として要確認にする。この変更は直前の区間も含めて一度にUndoできる。未解決区間や単語の組み替え後は、時刻が分からない欄を空欄にして手動入力を求める。「再生位置」で時刻を取り込み、±0.1秒で再生位置を調整できる。別の発言に未保存の本文・訳があっても対象発言の画面を開ける。対象発言の本文が未保存なら先に保存を求める。本文の完全一致、発言区間内、昇順、変更前の指紋を検証してから同じ発言の単語列だけを置き換え、Undoできるようにする。訳は対応した本文と言語を記録する。本文・言語変更、分割・結合、再起こし候補の採用後は訳を `stale` にする。

単語の開始・終了は数字でも個別に直せる。単語全体の▲▼は0.1秒単位で動かす。初期選択の「この単語以降も連動」では後続語の開始・終了を一緒に動かし、発話区間の終了も同じだけ延長または短縮する。「この単語だけ」では対象語だけを動かし、隣の語と重なればその境界を移動先へ揃える。保存時に延長した発話が次の発話の開始と重なる場合、次の発話の開始を延長後の終了に揃える。次の発話の単語時刻が新しい開始より前に残る場合は整列未解決として確認を求める。次の発話の終了を越える延長は保存しない。これらの変更は一度にUndoできる。元データに存在する0秒長の単語は、本文と語順を維持している限り位置移動・保存を許容する。0秒長の語は単独試聴できないため発話区間を再生して確認する。新しく0秒長を作る操作、負の長さ、発話区間外へ出る操作は適用しない。開始位置を変更した結果、元の単語だけが発話区間外に残り、安全に単語単位で収められる場合は「区間外の単語を仮移動」で長さを保った候補を入力欄へ反映する。これは保存せず、試聴後に時刻を確認して保存する。保存時に不正な時刻があれば、何語目のどの値が区間外か、逆転か、どの語同士が重なったかを表示して該当欄へ移る。発話の開始位置を保存しても単語時刻の調整画面は閉じず、入力中の単語時刻も保持する。

単語時刻の調整画面は画面内でスクロールし、最下部でも背後のレビュー一覧を動かさない。発話の終了位置は同画面で調整でき、単語時刻と別話者のクロストークは維持する。「終了前5秒を試聴」は新しい終了時刻の5秒前から再生し、発話全体が5秒未満なら開始時刻から再生する。

完成SRTは、言語未指定、外国語の訳が未入力または古い場合に停止する。「ドラフト」は問題を返し、SRT内の未訳を `[日本語訳 未完了]` と表示する。SRTは外国語で原語の次に日本語訳、日本語発言は原文だけを出す。Premiere JSONには訳を含めず、発言ごとの確認済み言語を `segment.language` へ出す。手修正原文の語間時刻が未確認なら整列未解決としてPremiere JSONを作らず、SRTと理由だけを返す。

## 外部サービス（任意設定）

ブラウザーへAPIキーを渡さない。OpenAI翻訳はサーバー環境の `OPENAI_API_KEY` と `TRANSLATION_MODEL` の両方がある場合、または起動中のサーバーへ専用コマンドで接続設定した場合だけ有効になる。専用コマンドの初期モデルは `gpt-4.1-mini` で、引数から変更できる。Responses APIへ `store:false` と厳格なJSON schemaを指定する。

日本語訳は「文脈単位で翻訳」から進める。同じ話者・言語で連続する未訳発言を、文末・時間・長さを目安にまとまりとして提案する。画面で前後の発言を含めたり外したりしてから、まとまり全体の日本語訳と、字幕用に各発言へ割り当てる訳を確認・編集する。OpenAIで下訳を生成する場合は、選んだ全発言と前後1発言の原文・言語・話者名を一度に送信し、全体訳と発言ごとの訳を候補として保存する。生成だけでは完成訳へ反映しない。接続設定がなくても手入力できる。下訳候補は各発言の日本語参考訳欄に編集可能な形で表示する。「訳・言語の要確認のみ」は、下訳候補に加え、訳の未入力・更新待ちと言語未指定も表示する。右欄で手直しして「訳を確定・保存」を押すと、その発言の訳を直接保存する。「文脈と全体訳を見る」は同じカード内で開き、別画面へ移動しない。他の発言に未保存の本文・訳があっても、現在の発言の訳は保存できる。文脈単位で区間への訳の割当をまとめて直す従来の画面も残す。保存はUndoで戻せ、原文・話者・言語・時刻は変更しない。言語未指定、日本語発言、手入力済みまたは完成済みの訳は下訳候補の対象外とする。文脈単位の生成・一括保存は未保存の本文・訳がある間は開始しない。従来の発言単位の生成ボタンも個別操作として残すが、文をまたぐ英語の一括翻訳には使わない。

起動中のサーバーに翻訳を接続するには、同梱の `翻訳接続設定.command` を使うか、`--configure-translation-running-server http://127.0.0.1:8901 --translation-model gpt-4.1-mini` を指定する。キーは非表示入力から認証済みローカルAPIへ渡し、実行中サーバープロセスのメモリだけに保持する。設定だけでは翻訳リクエストを送らない。キーのない環境では手入力・保存を引き続き利用できる。既存サーバーがこの機能を含むコードで起動している必要がある。

AssemblyAIライブ再取得は認証、使用モデル、ffmpegがそろう場合だけ有効になる。ボタンを押すまで音声送信や利用枠消費は始まらない。結果は本文・単語時刻・対象範囲・作成時の本文／話者／言語／区間指紋を持つ候補として保持する。採用時に指紋を再照合し、対象発言の単語列だけをAssemblyAI時刻へ交換する。話者、言語、レビュー区間の外枠は維持する。対象範囲外、逆転、空の単語時刻は拒否し、時刻を推測しない。本文と単語列が一致しない場合は整列未解決としてPremiere出力を保留する。今回は外部API実通信を行っていない。

候補ごとに採用可否と理由を表示する。単語時刻のない候補や作成後に対象が変わった候補は採用ボタンを無効にする。旧表示で最初の単語の先頭空白を含んだ指紋を持つ候補は、空白以外の本文・単語列・話者・言語・区間が完全一致する場合だけ採用できる。採用操作に失敗した場合は、画面上部だけでなく候補の横にも理由を表示する。

各発言の「完了後に本文と単語時刻へ反映」は既定で有効にできる。候補作成時の指紋が現在と一致し、未保存入力がなく、有効な単語時刻がある場合だけ自動採用する。無効にした場合は従来どおり候補比較後に手動採用する。再描画後も開いていた再起こし欄、スクロール位置、未保存入力を保持する。

本文表示、SRT、Premiere JSONでは、言語指定に依存せず日本語文字間の不要な空白を除く。英語・ドイツ語の単語間空白と単語時刻は維持する。表示上の整形だけなら本文変更や整列未解決として扱わない。

併記SRTでは外国語の原語だけを `<i>` で斜体にし、日本語訳との間に1行分の間隔を置く。SRT内の完全な空行は字幕ブロックの終端になるため、間隔行にはゼロ幅スペース（U+200B）を入れる。日本語の原語だけの字幕には装飾や間隔行を追加しない。Premiere Pro 2025の検証用プロジェクトで短い字幕の斜体と間隔行の表示を確認した。一方、長い原語が複数行に折り返される字幕では、保存済み字幕データに訳文があっても画面に訳文が見えない事例を確認した。

2026-09-26にSRT内の改行・対訳分割とPremiereの下寄せ・枠設定で防ぐ方針を確定した。原語はおおむね2行、訳も最大2行、間隔込み最大5行。収容不能や分割対応未確認は完成出力を止める。静止画・動画へ変換する案は採用しない。仕様と表示条件は [bilingual-srt-layout.md](bilingual-srt-layout.md) を参照。Premiereの実スタイル適合と、フォントや色を原語と訳で分ける自動設定は未検証・未実装。

「本文と言語指定の不一致」は、本文文字種と頻出語による控えめなローカル候補を、時刻・本文推定・手動指定・原文で比較する。これは音声判定ではない。短い語句と判定不能な本文は自動選択せず、低信頼候補は要確認として初期選択しない。利用者が選択して開始した時だけ、手動指定言語を維持したままAAIへ順次送信する。開始時の発言指紋が変わった項目は送信しない。現在の内容に対する未採用候補がある項目は重複送信せず、個別比較を案内する。

キーをファイルへ保存せず起動する場合は、既存サーバーを停止したうえで通常の起動引数へ次を追加する。端末の非表示入力から読み、キーはそのサーバープロセスのメモリだけに保持する。既存成功値に合わせモデルは `universal-3-5-pro` が初期値である。

```sh
--prompt-aai-key --aai-model universal-3-5-pro \
  --ffmpeg /absolute/path/to/ffmpeg
```

すでに確認画面が起動中なら、停止せず次の設定専用モードを実行できる。接続先はこのMacのloopback URLだけを受け付ける。キーを非表示入力し、認証済みローカルAPIを通して実行中プロセスのメモリへ渡す。作業state、操作履歴、応答、ログへキーを保存しない。

```sh
python3 python/multilingual_review.py \
  --configure-running-server http://127.0.0.1:8901 \
  --aai-model universal-3-5-pro \
  --ffmpeg /absolute/path/to/ffmpeg
```
