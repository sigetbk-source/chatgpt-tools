# 独立文字起こしの話者・区間修正画面

## 役割

既存 `premiere-speaker-repair` の文字起こし修正画面（`ec779c144ed9f42b4b1347d6f1576c9cb395a44a`）のカード構成、音声表示、スタイルを再利用した、独立master用の入口。2026-09-08に `transcript_static/styles.css` をコピーし、HTMLを必要な操作へ絞った。JavaScriptとサーバーは独立master APIに合わせて実装した。旧サーバー・既存案件は変更せず、履歴の移植はしていない。

`python/master_review.py` が `master_edit.edit` と `premiere_export.convert` を呼ぶ。話者変更・分割・結合の処理を画面用に別実装しない。Premiereを起動せずに利用できる。

## 起動

プロジェクトのディレクトリで、Python 3を使用する。追加パッケージは不要。Macローカルで使用する。

```sh
python3 python/master_review.py --master /absolute/path/master.json \
  --workspace /absolute/path/review-work \
  --media /absolute/path/source.mov \
  --speaker-ids /absolute/path/speaker-ids.json --port 8891
```

ブラウザーで `http://127.0.0.1:8891` を開く。`--media` は省略でき、その場合は音声なしで編集する。`--speaker-ids` は既存Premiere素材へ戻すときに確認済みの対応表を指定する。初回に省略した場合はUUIDを生成し、作業領域に保存する。名前で既存UUIDを推測しない。

入力masterと元音声は作業領域の外に置く。作業領域には元のmasterの保存先・内容の識別値、修正後master、話者UUID対応表、操作履歴を保存する。再開時は同じ入力を指定する。異なる入力や変更された元masterで同じ作業領域を使わない。音声の保存先も紐付ける。

## 操作

1. 各区間の話者を選ぶ。この区間だけの割当が変わる。
2. 「分割位置」で単語の境界を選ぶと「カーソル位置で分割」が有効になる。本文の単語境界に直接カーソルを置いてもよい。単語の途中には時刻を推測して付けない。分割後の話者は元区間と同じなので、必要なら選び直す。
3. 全文表示で「次の区間と結合」を押すと、次区間を現在の話者として結合する。重なりや異なる区間注釈があると拒否する。
4. 「元に戻す」「やり直す」で操作履歴を移動する。これも自動保存される。
5. 「Premiere用に保存」で、修正master・話者対応表・Premiere用JSONを新しい出力フォルダーへ保存する。画面に保存先を表示する。

本文は読取専用。本文の自由編集・新しい話者の追加・話者名の変更はこの入口では提供しない。同じ表示名の話者が複数いる入力は受け付けない。試聴はブラウザーが対応する音声・動画形式に限る。

古いタブからの変更は拒否し、最新状態を読み直す。エラー表示後は画面を確認して操作し直す。同じ作業領域を複数のサーバーで開くことも拒否する。

## Premiereへの引き渡し

この画面はPremiereへ直接書き込まない。出力の `premiere.json` は共通 `safe-writeback.writeback` のcandidateに渡せるが、対象の照合情報、直前のexport、読み戻し期待値、永続バックアップは別途必要。[統合仕様](integration.md)の制約を維持する。

ファイル保存成功を「Premiereへ反映済み」と表示しない。任意素材での読み戻し許容規則・対象binding・バックアップ処理が整った段階で、共通writebackを画面へ接続する。既知サンプルの過去の期待値を別の編集内容に流用しない。
