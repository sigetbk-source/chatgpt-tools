# Hawks Magic Chart

福岡ソフトバンクホークスの優勝マジックを、検証済みの日次データから固定レイアウトの PNG へ再描画します。この README が LLM 非依存の実装・仕様の正本です。

## 描画仕様

- Pillow を使う決定論的な Python 描画
- 2880 × 1620 px（16:9）の静止画 PNG
- 日付順の step chart。横ばいは水平、減少日は垂直に落下
- 点灯日を最初の点とし、それ以前へ線を延ばさない
- 各日に `M<number>` を表示する
- 試合日は折れ線直下に対戦相手ロゴ、試合なしの日はロゴなし
- タイトルは `’26 福岡ソフトバンクホークス 優勝マジック推移`
- タイトル左にホークスの固定ロゴを表示する
- 既存 PNG を編集せず、JSON から毎回再生成する

## 固定ロゴ資産

`assets/` の `hawks_sh.png`、`F.png`、`L.png`、`M.png`、`E.png`、`B.png` を再利用します。文字やフォントでロゴを代用しません。対戦相手の円は同一サイズで、M・E・B は光学補正済みです。

出典、正規化処理、再配布上の注意は [`assets/SOURCE.md`](assets/SOURCE.md) を確認してください。

## 入力

JSON の `data` に、点灯日から出力最終日までを1日ずつ昇順で指定します。

```json
{
  "footer": "試合なしの日は直前のマジックを持ち越し。",
  "data": [
    {"date": "2026-08-05", "magic": 37, "opponent": "F"},
    {"date": "2026-08-06", "magic": 37, "opponent": "F"},
    {"date": "2026-08-07", "magic": 35, "opponent": "L"}
  ]
}
```

対戦相手コード:

- `F`: 北海道日本ハム
- `L`: 埼玉西武
- `M`: 千葉ロッテ
- `E`: 東北楽天
- `B`: オリックス
- `null`: 試合なし

## データ検証

`render_magic_chart.py` は描画前に次を検証し、不正な入力では停止します。

- `data` が空でない
- 日付が重複せず、1日ずつ連続している
- マジックが0以上の整数で、前日から増えていない
- 試合なしの日は、直前のマジックを持ち越している
- 対戦相手コードが対応済みである

数値と対戦相手を更新するときは、ホークス公式・NPBを優先し、必要に応じて別の信頼できる情報源で照合してから JSON へ反映します。

## 実行

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 render_magic_chart.py example_2026-08-20.json hawks_magic_2026-08-20.png
```

## 出力と確認

指定パスへ 2880 × 1620 px の PNG を出力します。生成後は寸法に加えて、最初の点に左からの線がないこと、水平・垂直の step、全数値、試合日ロゴ、試合なし日のロゴ非表示を確認してください。
