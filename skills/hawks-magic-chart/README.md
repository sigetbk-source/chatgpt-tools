# Hawks Magic Chart

福岡ソフトバンクホークスの優勝マジックを、検証済みの日次JSONから固定レイアウトのPNGへ再描画します。2026年8月20日に承認された白背景版の外観を正本とします。

## 維持する外観

- 2880×1620px、白背景
- 太字タイトル、黒／ホークスイエローの二重罫線
- 期間と最新マジックを示す黒いピル型表示
- 1刻みの薄い点線グリッド
- 黄色のstep line、黒い点、`M`を付けない数値
- 旧Skillに保存された球団ロゴPNGと88px描画枠
- 下部の日付と「日付」ラベル

状態アイコンのため、プロット上端だけを旧版より50px下げています。それ以外の色、書体、線幅、軸、球団ロゴ、主要座標は承認済み版を維持します。

## 固定画像資産

`assets/`の`hawks_sh.png`、`F.png`、`L.png`、`M.png`、`E.png`、`B.png`は承認済み版をそのまま使います。状態アイコンも同じ場所の`magic_lit.png`、`magic_extinguished.png`、`magic_relit.png`、`magic_champion.png`を読み込みます。詳細は[`assets/SOURCE.md`](assets/SOURCE.md)を参照してください。

## 入力

点灯日から出力最終日までを1日ずつ昇順で指定します。

```json
{
  "simulation": false,
  "data": [
    {"date": "2026-08-05", "magic": 37, "opponent": "F"},
    {"date": "2026-08-06", "magic": 36, "opponent": null},
    {"date": "2026-08-07", "magic": null, "opponent": "L"},
    {"date": "2026-08-08", "magic": 35, "opponent": null}
  ]
}
```

- `magic`: 点灯中は0以上の整数、消滅中は `null`
- `opponent`: `F`、`L`、`M`、`E`、`B`。ホークスの試合なしは `null`
- 試合なし日にも他球団の結果でマジックは減少・消滅・再点灯し得る
- 最初の整数を点灯、整数から`null`を消滅、消滅後の整数を再点灯として自動判定する
- `magic: 0`になった最初の日を優勝決定として自動判定し、以後の値は0のままとする
- 再点灯値は消滅直前より必ず小さくする
- 同じ点灯区間内でマジックを増加させない

## 日付ごとの事実確認

JSONの追加・修正前に、対象日ごとの「日付／試合あり・なし・中止／対戦相手／マジック／根拠URL」を作業記録に残します。試合有無はNPBまたは球団公式の日付行と試合終了情報で確認し、マジックは当日終了時点の根拠で別に確認します。検索要約は隣の日の試合を含む場合があるため、日付との対応が曖昧なら本文・日程表を開きます。確認できない日を前日の対戦相手や通常の3連戦から補完しません。

- 試合なし・中止日は `opponent: null`。未確認と試合なしを混同せず、未確認のまま完成版を出さない。
- シーズン終盤は単発試合、2連戦、振替試合、移動日を挟む変則日程が増える。曜日や3連戦を前提にせず、各日の実施状況とカード終了日を最新の公式日程で確認する。
- マジックが同じでも試合がないとは限らず、試合なしでも他球団の結果でマジックは変わり得る。2項目を独立して確認する。
- 確認済み記録とJSONを日付で照合し、生成後も追加・修正日のロゴの有無と数値を照合する。例：2026/9/3は試合なし、M18、ロゴなし。9/1・2のFを9/3へ延長しない。
- 日付付きの入力スナップショットを更新する場合は、新しい終了日に対応した別ファイルに保存する。古い終了日のファイル名のまま期間を延長しない。
- 過去カード用はカード終了日でJSONを切り、その日を画像タイトル・最終点・添付先と照合する。

`magic_data.py`の検証は日付の連続性・値・状態遷移を確認しますが、実際の試合日程は参照しません。`F`は有効な球団コードなので、休養日に誤入力しても構造検証だけでは検出できません。

## 消滅期間の表示

- 黄色線は消滅日に切り、再点灯日は新しい線として開始する
- 消滅日の直前値を灰色で表示し、その上に消滅アイコンを置く
- 消滅期間中の対戦球団ロゴは、消滅直前のマジック値を基準に通常時と同じ垂直位置へ並べる
- 点灯・消滅・再点灯・優勝決定アイコンは球団ロゴと同じ88px描画枠を使い、該当数値の直上に置く
- 点灯は赤い稲妻、再点灯は赤い循環矢印、優勝決定はトロフィーで表す

## 実行

```bash
python3 render_magic_chart.py input.json output.png
```

状態アイコンの固定PNGを書き出す場合は次を実行します。

```bash
python3 scripts/create_event_icons.py
```

生成後は寸法、日付、数値、状態遷移、球団ロゴ、旧版の外観が維持されていることを目視確認します。`simulation: true`では下端にダミー表記を追加します。
