# Hawks Magic Chart

1. Read `README.md` for the canonical input, rendering, validation, and output specification.
2. Verify every new date, magic state, magic number, and opponent before editing JSON. Preserve every calendar date; use `opponent: null` when the Hawks do not play and `magic: null` while the magic is extinguished.
3. Reuse `assets/` without substituting team logos. Read `assets/SOURCE.md` before redistribution. The state icons are generated by `scripts/create_event_icons.py`.
4. Run `render_magic_chart.py`. Verify the PNG is exactly 2880 × 1620, all active segments match the JSON, inactive intervals have no line, and 点灯・消滅・再点灯 icons appear directly above the related magic value at the same displayed size as opponent badges. During an inactive interval, align opponent badges to the last active magic level.
5. Report the covered date, final magic state/number, verification state, and output path separately.
